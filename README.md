# MarriageBio - தமிழ் திருமண பயோடேட்டா மேக்கர் (Tamil Marriage Biodata Maker)

A modern, culturally rich mobile & web application to generate auspicious Tamil Hindu marriage biodatas with South Indian horoscope charts, advanced photo studio, high-res PDF generation, and image export.

## ✨ Key Features
- **6 Authentic Tamil Themes:** Traditional Marital Maroon & Gold, Madurai Meenakshi Temple, Chettinad Royal Ivory, Kanchipuram Silk Saree, Modern Minimalist, and Divine Astrological.
- **South Indian Horoscope Charts (ஜாதகக் கட்டம்):** Complete 12-house interactive Rasi (ராசி) and Navamsam (நவாம்சம்) charts with Lagna, planet placements, and auto-generated dosham summaries.
- **Advanced Photo Studio:** Zoom, rotate, border styles (Traditional Gold, Floral, Temple Arch, Oval), Gaussian edge feathering/blur for seamless background blending.
- **Tamil Voice Input (குரல் பதிவு):** Speech-to-text dictation in Tamil for easy data entry.
- **Instant Export:** High-resolution document PDF (printable on A4) and high-quality image PNG/JPEG export.
- **Permissions & PWA:** Fully configured mobile permissions (Camera, Gallery, Microphone) and standalone installable Progressive Web App (PWA) support.

## 🚀 Getting Started
```bash
# Install dependencies
npm install

# Start local development
npx expo start

# Run tests
npx tsc --noEmit
npx expo-doctor
```
